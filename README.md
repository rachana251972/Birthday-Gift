# 🎂 Birthday Website for Bhaiya

A beautiful space-themed birthday surprise website with memory timeline.

## Features
- Interactive space background with particles.js
- Memory timeline with photos
- Letter from the heart
- Birthday wish counter
- Blow candles confetti celebration
- Background music support
- Fully responsive (mobile & desktop)

## Structure
```
birthday-website/
├── index.html      # Main webpage
├── style.css       # Styles
├── script.js       # JavaScript
├── media/
│   ├── music/
│   │   └── song.mp3        # Birthday song
│   └── photos/
│       ├── birth.jpg       # Birth photo
│       ├── school.jpg      # School days
│       ├── sport.jpg       # Sports memory
│       ├── highschool.jpg  # High school
│       └── college.png     # College graduation
└── README.md
```

## How to Add Content

### Photos
Place photos in `media/photos/` with these names:
- `birth.jpg` - Baby/birth photo
- `school.jpg` - School days
- `sport.jpg` - Sports/achievements  
- `highschool.jpg` - High school
- `college.png` - College graduation

### Music
Place your birthday song as `song.mp3` in `media/music/`

## Technologies
- HTML5, CSS3, JavaScript
- Tailwind CSS (CDN)
- Particles.js (space background)
- AOS (scroll animations)
